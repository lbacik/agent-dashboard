## Summary

Implemented most of contract artifact preview/download (parent #176; blocked by
#182, merged). From a contract Attempt page an operator can preview any archive
member inline (rendered by `media_type`) and download it, both verified (size +
`sha256`) against the `attempts show` manifest. Torn reads of unsealed archives
refetch once, then report "changing, try again"; sealed mismatches are errors.
All source changes are in the working tree, uncommitted; tests, README,
